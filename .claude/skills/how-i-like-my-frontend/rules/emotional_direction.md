# Emotional Direction Rules

Emotional direction is the deliberate shaping of how a user feels when they experience the product. Great design creates a specific, consistent emotional state — not a vague aesthetic impression.

---

# The Core Principle

Every design choice communicates an emotional tone. Color, type, motion, spacing, imagery, and copy all send emotional signals. When they align, the design creates a feeling. When they conflict, the design creates noise.

Before beginning any design, answer: how should the user feel when they land on this page?
Then audit every design decision against that answer.

---

# Emotional Archetypes

These are the most useful starting points for emotional direction in SaaS and web products:

Precise and Intelligent:
- Signals: dark background, monochromatic palette, tight typography, minimal motion, data visualization as visual element
- Products: analytics tools, developer platforms, security products, fintech

Bold and Confident:
- Signals: high-contrast type (very large, heavy weight), limited palette, strong asymmetric layouts, purposeful negative space
- Products: agencies, creative studios, tools for professionals

Warm and Approachable:
- Signals: light palette, rounded type, friendly illustrations, higher line heights, warm neutrals
- Products: consumer apps, education, health and wellness

Playful and Energetic:
- Signals: saturated accent colors, bouncy motion, irregular layouts, personality-driven copy, expressive illustrations
- Products: consumer social, gaming, creative tools for non-professionals

Premium and Exclusive:
- Signals: restrained palette, serif display type, large negative space, slow deliberate motion, almost no color
- Products: luxury brands, high-end SaaS, design-forward products

Rule:
Identify the archetype that fits the product. Use it as a filter for every design decision. If a decision does not reinforce the archetype, question it.

---

# Aligning Copy and Visual Tone

Copy and visual design communicate simultaneously. When they conflict, credibility collapses.

Conflicts to avoid:
- Casual, friendly copy ("Hey! Let's get you set up") on a cold, corporate visual system
- Serious, measured copy ("Enterprise-grade security for regulated industries") on a playful, colorful visual system
- Technical jargon in copy on a consumer-friendly visual system

Alignment examples:
- Dark, minimal, precise visual system + direct, confident copy with no filler
- Warm, rounded, accessible visual system + conversational copy with contractions and humor
- High-contrast, bold visual system + punchy, short copy that makes bold claims

Rule:
Read the hero copy aloud while looking only at the visual design. If it feels like someone else wrote the copy for a different site, the tone is not aligned.

# Color and Emotional Temperature

Color communicates temperature before it communicates anything else.

Cool tones (blues, greens, dark greys): Calm, controlled, precise, trustworthy. Lower emotional urgency.
Warm tones (oranges, ambers, reds): Urgency, energy, warmth, creativity. Higher emotional charge.
Neutral monochrome: Confidence, editorial, absence of emotional temperature — lets the content do the work.
Saturated color: Energy, boldness, fun, youth.
Desaturated color: Premium, sophisticated, restrained.

Rule:
The color temperature of the dominant palette should match the desired emotional temperature of the user experience. A calm, analytical product should lean cool. An energetic, social product should lean warm.

---

# Motion and Emotional Pace

The speed and style of motion communicate emotional pace.

Slow, deliberate motion (2-3 second transitions, graceful easing):
Communicates confidence, premium, deliberateness. Feels considered.

Fast, snappy motion (150-250ms, immediate response):
Communicates efficiency, energy, directness. Feels productive.

Bouncy, spring-based motion:
Communicates playfulness, friendliness, approachability. Feels human.

Heavy, dramatic motion (long scroll animations, parallax):
Communicates gravitas, storytelling, depth. Feels cinematic.

Rule:
The motion pace should match the product's emotional pace. A fast productivity tool should use snappy interactions. A premium editorial experience should use slower, more deliberate transitions.

---

# Spacing and Emotional Openness

Spacing communicates psychological openness and exclusivity.

More space: openness, confidence, premium, breathing room. Invites lingering.
Less space: density, urgency, information richness. Invites efficiency.

Premium brands (Apple, Stripe, Linear) use significantly more whitespace than average because it communicates "we are not competing for attention — we deserve it."

Rule:
If the design should communicate premium or confidence, add more space than feels natural. If the design should communicate efficiency and information density, be deliberate about tightening it — do not just use default spacing.

---

# Emotional Consistency Audit

Before shipping, perform an emotional consistency audit:

1. Write down the desired emotional state in one sentence.
2. List the five strongest visual elements on the page (hero type treatment, primary color, hero visual, button style, dominant section pattern).
3. For each element, ask: does this reinforce or contradict the desired emotional state?
4. For each contradiction: change the element to align, or justify why it must remain.

Rule:
More than two contradicting elements means the emotional direction was not decided before designing. Stop, define the direction, then audit.

---

# Emotional CTA Design

The CTA carries the emotional invitation to act. Its design should align with the emotional state the page has built.

If the page is bold and confident: the CTA should be direct and large. "Start now." "Get access." No softening language.
If the page is warm and approachable: the CTA can be encouraging. "Let's get started." "Join for free."
If the page is precise and intelligent: the CTA should be measured and specific. "Request early access." "See the platform."

Rule:
Generic CTAs ("Get started for free") always feel tacked on. A CTA written for the product's specific emotional direction converts better and maintains the page's cohesion to the final moment.
