# Visual Hierarchy Rules

Visual hierarchy is the invisible architecture that tells the eye where to go and in what order. Without it, pages look busy and users leave without understanding the product. With it, attention moves naturally from the most important information to the next.

---

# The Core Principle

Every section must have exactly one dominant element. Everything else supports that element. When two or more elements compete for dominance, neither wins and the viewer's attention dissipates.

Before designing any section, answer: what is the single most important thing the user should perceive here?

---

# The Five Hierarchy Levers

Hierarchy is created through these tools, in rough order of power:

1. Size — larger elements receive attention first. The headline should be visually larger than anything else.
2. Weight — heavier font weight draws the eye before lighter weight at the same size.
3. Color and contrast — high-contrast elements are seen before low-contrast elements.
4. Position — top-left receives attention first in F-pattern scanning cultures. Center receives secondary attention.
5. Whitespace — isolated elements with space around them read as more important than elements surrounded by other elements.

Rule:
Use at least 3 of the 5 levers on the primary element of each section. An element that is only large but shares weight, color, position, and density with others does not dominate.

---

# Scan Path Engineering

Users do not read pages — they scan them. The design should create a natural scan path that guides the eye through information in order of importance.

Standard scan path for a landing page hero:
Headline (largest, heaviest) → subheading (medium, positioned close below) → CTA (color contrast, clear isolation) → supporting visual (positioned to reinforce, not compete)

Rule:
Trace the expected scan path on any design. If the eye stops before reaching the CTA, or jumps to the wrong element first, the hierarchy is wrong.

---

# Focal Point Per Section

Each section should have one focal point — the element that catches the eye first.

Heroes: The headline or a dominant visual element, never both equally.
Feature sections: One leading feature that is visually larger than supporting features.
Testimonials: One quote, not a grid of equal-weight testimonials.
Pricing: The recommended plan, clearly elevated above alternatives.
CTA sections: One action. If two actions exist, one must be primary and one secondary.

Rule:
If you cannot identify the focal point of a section in under 2 seconds, it does not have one. Redesign.

---

# Text Hierarchy

Three text levels are the minimum. More than five becomes noise.

Level 1 — Headline: The statement the user must read. Maximum visual weight.
Level 2 — Supporting text: Expands the headline. Smaller, lighter.
Level 3 — Body/detail: Substantiates the claim. Readable, not dominant.
Level 4 (optional) — Labels/metadata: Tags, categories, small notes. Recedes.
Level 5 (optional) — Legal/footnotes: Deliberately low-contrast, visually quiet.

Rule:
If levels 1 and 2 are too visually similar, increase the size or weight of level 1. The headline should be immediately distinguishable from 10 feet away.

---

# Color and Contrast as Hierarchy

High-contrast elements demand attention. Use this deliberately.

Accent color on one element per section maximum: CTA button, key number, important label.
Low-contrast secondary elements recede and support without competing.
Never use accent color on more than 3 elements per full page — it loses meaning.

Rule:
If the accent color appears on 5+ elements on the page, it no longer signals importance. It has become wallpaper.

---

# Size Contrast

The ratio between the largest and smallest elements on a page signals design confidence.

Weak: Headline 28px, body 16px. A 1.75x ratio. Barely any contrast.
Strong: Headline 72px, body 16px. A 4.5x ratio. Clear dominant element.
Bold: Display 96px, body 16px. 6x ratio. Confident, editorial.

Rule:
For hero sections, never let the headline-to-body size ratio drop below 3x. Below that, nothing dominates and everything competes.

---

# Hierarchy Across Sections

Hierarchy is not just within a section — it operates across the full page.

The hero section should have the highest visual energy on the page.
Subsequent sections should step down in visual intensity while maintaining readability.
The final CTA section should have elevated intensity again — second only to the hero.

Rule:
If every section looks equally energetic, the page has no rhythm. If every section looks equally muted, the page has no impact. Vary the visual intensity across sections deliberately.

---

# Common Hierarchy Failures

Everything is the same size: The most common failure. Add size contrast aggressively.
The CTA is not visually distinct: If the CTA button blends into the section, fix the contrast before anything else.
Secondary elements competing with primary: Supporting text, icons, or images drawing as much attention as the headline. Reduce their visual weight.
Multiple focal points per section: Two large elements of equal weight. One must yield.
Logo or navigation drawing attention from content: Navigation should visually recede. If it competes with the headline, reduce its contrast.
