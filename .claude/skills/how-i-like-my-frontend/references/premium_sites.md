# Premium Sites

Sites worth studying for specific design qualities. Each entry notes what specifically makes it worth examining.

---

# Linear

What Makes It Notable:
Exceptional dark system design. Spacing discipline that feels architectural. Typography with perfect hierarchy. Motion that is noticeable once and then invisible.

Study For:
- How to use spacing as a primary design tool
- Dark background text opacity hierarchy
- Subtle hover states
- Navigation design with active states

URL: linear.app

---

# Stripe

What Makes It Notable:
The gold standard for SaaS landing page design. Information density balanced with whitespace. Strong typographic hierarchy. Product UI integrated naturally into marketing pages. Bento-style feature showcases done correctly.

Study For:
- How to present complex technical products clearly
- Bento grid implementation
- Gradient usage that is purposeful, not generic
- Trust building through design quality

URL: stripe.com

---

# Vercel

What Makes It Notable:
Dark minimal system with extreme restraint. Almost no color. Typography doing all the work. Bold claims stated plainly without visual decoration.

Study For:
- How to build a premium dark system with almost no color
- Confidence through restraint
- Developer-facing design that does not feel cold
- Typography as the primary visual element

URL: vercel.com

---

# Raycast

What Makes It Notable:
Strong use of product UI embedded in the marketing page. Custom gradient meshes that feel deliberate rather than random. Motion design that demonstrates the product. Dark luxury positioning for a developer tool.

Study For:
- How to show product UI without making it look like a screenshot dump
- Gradient mesh backgrounds done correctly
- Section transitions
- Hero animation connected to product concept

URL: raycast.com

---

# Loom

What Makes It Notable:
Consumer-facing product with warm, approachable design. Strong social proof integration. Video-as-hero done correctly. Conversational copy matching the visual warmth.

Study For:
- Warm SaaS design (not cold or generic)
- Video integration in hero
- How to make enterprise-used products feel human
- Copy-visual tone alignment

URL: loom.com

---

# Framer

What Makes It Notable:
Product that demonstrates its own capabilities. Motion design integrated throughout. Strong grid work. Product UI shown in creative context.

Study For:
- How to demonstrate a tool by using it
- Scroll animations on feature reveals
- Product embedding in marketing context

URL: framer.com

---

# Clerk

What Makes It Notable:
Dark system with excellent gradient usage. Strong grid discipline. Clear feature hierarchy. Good component integration showing actual UI.

Study For:
- Dark system with tasteful gradient accents
- Feature section bento layout
- Pricing table design

URL: clerk.com

---

# Resend

What Makes It Notable:
Extremely restrained dark design. Near-monochrome. Typography-first. Code snippets as visual elements. Makes technical content feel premium.

Study For:
- Maximum restraint in dark design
- Using code as a visual element
- Technical product positioning through design
- What minimal looks like at its best

URL: resend.com

---

# Arc Browser

What Makes It Notable:
Expressive and human. Breaks SaaS conventions intentionally. Strong personality in both copy and design. Motion with genuine character.

Study For:
- How to break SaaS design conventions with intention
- Personality-driven design
- Motion that feels alive
- Consumer-facing tone for a technical product

URL: arc.net
