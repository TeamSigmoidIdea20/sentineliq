# Inspiration Sources

---

# Awwwards

Purpose:
Curated gallery of award-winning websites judged on design, creativity, usability, and content.

Best For:
- Finding current premium design benchmarks
- Discovering unconventional layout approaches
- Studying top-tier motion design and scroll experiences
- Level 3 and Level 4 reference work

How to Use:
- Browse "Site of the Day" for current top-tier work
- Filter by industry category to find relevant examples
- Look at the judging breakdown to understand what scores highly
- Study the source code of winning sites for technique extraction

Risk:
Some Awwwards sites prioritize spectacle over usability. Do not copy complexity — extract principles.

---

# Godly.website

Purpose:
Infinite-scroll gallery focused on modern web design. Updated frequently. Skews toward SaaS, startup, and tech product design.

Best For:
- Fast browsing of current SaaS design trends
- Finding inspiration closest to product landing pages
- Identifying what "current premium" looks like for startups
- Quick reference before beginning a landing page build

How to Use:
- Scroll until something stops you. Screenshot it.
- Group multiple screenshots by what they share (dark systems, strong type, specific layouts)
- Use search for specific styles or product categories

Risk:
Godly reflects trends. Heavy use can lead to trend-following rather than differentiation.

---

# Pinterest

Purpose:
Visual reference aggregation. Best for collecting and organizing mood boards by specific design attributes.

Best For:
- Concept imagery for visual storytelling
- Typography inspiration and pairings
- Color palette exploration
- Layout pattern discovery
- Pre-design mood board creation

How to Use:
- Search for specific queries: "SaaS landing page dark", "hero section typography", "web design minimal", "[product type] UI"
- Create boards for each project to store collected references
- Pin from multiple sources — do not pin only one style

Risk:
Pinterest surface repeats popular content. Dig past page 2 to find less common references.

---

# Dribbble

Purpose:
Design community sharing shots and case studies. High volume of UI design work from professional designers.

Best For:
- Component and UI element inspiration (buttons, cards, forms, navigation)
- Color palette ideas from specific design contexts
- Micro-interaction and state design examples
- Finding designers whose work matches a desired direction

How to Use:
- Search specific UI elements: "pricing table dark", "hero button states", "onboarding flow"
- Follow designers whose work consistently matches your target aesthetic
- Look at full project shots, not just single components

Risk:
Dribbble shots are often unrealistic — designed for visual impressiveness rather than functional implementation. Adapt concepts, do not copy implementations directly.

---

# Screenlane

Purpose:
Mobile and desktop UI pattern library organized by screen type and interaction pattern.

Best For:
- Finding specific screen type examples (onboarding, empty states, settings screens)
- Reference for functional UI patterns
- Mobile design reference

How to Use:
- Search by screen type or interaction pattern
- Good for "how do premium products handle this specific screen" questions

Risk:
Less focused on marketing/landing page design than the others. Best for product UI, not hero sections.

---

# Land-book

Purpose:
Curated gallery specifically for landing pages.

Best For:
- Landing page pattern research
- "How do premium products present this product category" research
- Quick reference for specific sections (pricing, features, testimonials)

How to Use:
- Search by product category or section type
- Compare how multiple products in the same category approach the same sections

Risk:
Quality varies. Not all featured pages meet premium standards. Selective use.
