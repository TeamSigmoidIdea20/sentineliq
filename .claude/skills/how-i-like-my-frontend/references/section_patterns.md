# Section Patterns

---

# Hero Section

Purpose:
First impression. Establishes emotional tone and communicates the product's core value in under 5 seconds.

Required Elements:
- Headline (the single most important statement on the page)
- Sub-headline (expands or supports the headline)
- Primary CTA (one action, not two)
- Visual element (imagery, UI screenshot, or strong typographic treatment)

Optional Elements:
- Secondary CTA (ghost or text variant)
- Social proof teaser (logos, user count, rating)
- Navigation above

Anti-patterns:
- Generic gradient background with no visual element
- Centered layout with no asymmetric tension
- Headline that describes category instead of specific value
- Two equally weighted CTAs competing

Strong examples:
- Left-weighted headline at 72-96px + product UI on right filling the remaining space
- Full-bleed concept video with text overlay and strong gradient for legibility
- Bold typographic hero with no imagery and maximum type scale

# Logo Bar / Social Proof Strip

Purpose:
Builds immediate trust by showing recognizable brands using the product.

Required Elements:
- 4-8 logos from recognizable or aspirational companies
- Low-contrast treatment — logos should be subtle, not celebrated

Implementation:
- Grayscale or low-opacity logos on dark backgrounds
- Horizontal scroll on mobile
- Optional: label "Trusted by teams at" above

Anti-patterns:
- Logos in full color competing with each other
- Generic companies with no name recognition
- Missing the section entirely — trust must appear early

---

# Feature Showcase

Purpose:
Demonstrates what the product can do in enough detail to create desire.

Common patterns:
- Bento grid: varied card sizes with UI screenshots and brief labels
- Alternating rows: text left, UI right, alternating per feature
- Tabbed interface: features switchable by tab with animated content
- Timeline: steps in a workflow shown sequentially

Required for each feature:
- Clear statement of what the feature does
- Visual evidence (screenshot, UI demo, or illustration)
- Optional: specific outcome or metric

Anti-patterns:
- Three identical cards with icon, title, two sentences
- Feature list with no visual evidence
- More than 6-8 features in one section (overwhelm)

---

# How It Works

Purpose:
Reduces skepticism by explaining the mechanism clearly. Makes the product feel real and believable.

Patterns:
- Numbered steps with brief descriptions (3-4 steps)
- Timeline with visual checkpoints
- Two-column: step on left, animated UI demonstration on right

Required:
- 3-5 steps maximum (more creates overwhelm)
- Each step maps to a user action or benefit
- Visual confirmation that the step is real

Anti-patterns:
- Steps described in passive voice ("Data is analyzed...")
- Steps without any visual evidence of the step
- More than 5 steps (condense into fewer, higher-level steps)

# Social Proof / Testimonials

Purpose:
Provides narrative evidence from real users. Converts skeptics who respond to human stories.

Patterns:
- Grid of 2-3 testimonials (most common)
- Single large featured testimonial (highest impact, lowest credibility risk)
- Scrolling ticker of short testimonials
- Case study callout linking to full story

Required for each testimonial:
- Real name, real title, real company
- Specific outcome or specific detail (not "it's great")
- Photo or company logo (increases credibility significantly)

Anti-patterns:
- Anonymous testimonials
- Generic praise ("This tool changed everything")
- No photo, no company logo
- Grid of 9+ equal-weight testimonials

---

# Statistics Section

Purpose:
Quantifies impact with specific numbers. Fast to scan, immediately persuasive for number-oriented prospects.

Required:
- Numbers that are specific and credible (12,000 users, not "thousands")
- Context for each number (what the number measures)
- Optional: brief label explaining the metric

Anti-patterns:
- Round numbers that feel made up ("100,000+")
- Numbers without context (what does "500M" mean?)
- More than 4-5 statistics (diminishing returns)
- Statistics not relevant to the buyer's decision

Implementation:
- Count-up animation when section scrolls into view
- Large display type for numbers (60-80px)
- Smaller label text below each number

---

# Pricing Section

Purpose:
Converts willing prospects by removing ambiguity about cost and what they get.

Structure:
- 2-4 tiers (3 is the researched optimum)
- Recommended tier visually elevated (background color, border, badge)
- Clear list of what each tier includes
- One CTA per tier

Anti-patterns:
- More than 4 tiers (analysis paralysis)
- No recommended tier highlighted
- Hidden pricing that requires a sales call (without justification)
- Equal visual weight on all tiers

---

# Final CTA Section

Purpose:
The last invitation before the user leaves. Should re-establish the aspiration set in the hero.

Required:
- Strong headline that echoes or answers the hero
- One primary CTA
- Optional: secondary supporting line (start free, no credit card)

Emotional design:
- Should feel like a return to the hero's energy level
- Can include the hero's visual element at reduced scale
- Should not feel like an afterthought

Anti-patterns:
- "Get started today" with no supporting context
- Same CTA copy used throughout the entire page
- Low visual energy (the most-neglected section on most landing pages)
