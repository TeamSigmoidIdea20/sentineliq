# Final Polish Checklist

Run before shipping any page. Every item must be checked. Incomplete sections are noted for follow-up.

---

# Visual Hierarchy

- [ ] Hero has one dominant visual element — the eye knows where to go first
- [ ] Each section has one focal point
- [ ] Headline-to-body type size ratio is minimum 3x in hero, 2x in other sections
- [ ] No section has three elements of equal visual weight competing
- [ ] The final CTA section has elevated visual energy — not an afterthought

---

# Typography

- [ ] Headline weight is 700+ in hero section
- [ ] Body text is 15-17px with line-height 1.5-1.7
- [ ] Label and tag text is slightly letter-spaced (0.05-0.1em) if uppercase
- [ ] Large display text is set with negative letter-spacing (-0.01 to -0.03em)
- [ ] Text colors are tiered: primary (90%), secondary (55%), tertiary (35%) opacity or equivalent
- [ ] No pure #000000 on white or pure #FFFFFF on dark backgrounds
- [ ] No orphan words (single words on the last line) in key headlines

---

# Spacing

- [ ] Section vertical padding is 80px minimum, 120px+ for hero and hero-level sections
- [ ] Card internal padding is 24px minimum
- [ ] Grid gaps are consistent (not varying per section)
- [ ] Elements have breathing room — nothing feels cramped
- [ ] Body text column width is constrained (max 680px or 70 characters per line)

---

# Color

- [ ] Palette is 3 colors maximum (dominant, accent, neutral system)
- [ ] Accent color appears on 3-5 elements max across the full page
- [ ] No unintentional gradients (background colors are deliberate choices)
- [ ] Text contrast passes: minimum 4.5:1 for body text, 3:1 for large text

---

# Anti-Slop Cleared

- [ ] No purple/violet gradient backgrounds
- [ ] No glow or neon halo effects (or one maximum, deliberately chosen)
- [ ] No more than one glassmorphism element
- [ ] No three identical-structure feature cards
- [ ] No over-centered layouts (at least some sections use asymmetry)
- [ ] Hero section is not: centered text + gradient + particle field
- [ ] No purposeless animations

---

# Interaction States

- [ ] All buttons: hover state present
- [ ] All buttons: active/pressed state present (scale 0.97 or background darken)
- [ ] All buttons: focus ring present and styled
- [ ] All clickable cards: hover state present (elevation or border highlight)
- [ ] All text links: hover state present
- [ ] All form inputs: focus state present (border color shift to accent)
- [ ] Loading states present on all async operations

---

# Motion

- [ ] Hover transitions are 150-250ms (not instantaneous)
- [ ] Scroll reveals are subtle (20-30px translateY, opacity 0-1, 400-550ms)
- [ ] Scroll reveals trigger once only (not on re-scroll)
- [ ] State transitions (tab panels, accordions, modals) are not instantaneous
- [ ] prefers-reduced-motion media query disables animations
- [ ] No animations faster than 100ms or slower than 800ms

---

# Mobile

- [ ] Section padding on mobile: 48-64px vertical minimum
- [ ] No horizontal overflow on any screen width
- [ ] Font sizes readable: headline 32-40px minimum on mobile, body 15-16px
- [ ] Button tap targets: minimum 44x44px
- [ ] Navigation works on mobile (hamburger or simplified menu)
- [ ] Hero layout stacks cleanly (visual below text on mobile)
- [ ] Video replaced by still image on mobile

---

# Visual Assets

- [ ] No generic stock photography
- [ ] No placeholder or lorem ipsum text anywhere
- [ ] All images load (no broken images)
- [ ] Images fade in on load (no snapping)
- [ ] Hero visual is concept-specific to the product

---

# Content

- [ ] Tagline is specific to this product (not interchangeable with competitors)
- [ ] Every statistic is specific (not rounded or generic)
- [ ] Social proof includes real names, titles, and company logos or names
- [ ] No generic CTA copy ("Get started today" without context)
- [ ] All copy is final (no draft language, no brackets)

---

# Performance

- [ ] Images are compressed (WebP preferred, JPEG fallback)
- [ ] No console errors visible in browser developer tools
- [ ] Page loads in under 3 seconds on a simulated fast 3G connection (Chrome DevTools)
- [ ] Hero video is under 8MB and only loads on desktop

---

Shipping criteria: All checked. Or: all checked with documented exceptions that are tracked for the next iteration.
