# UI Critique Prompt

Use this prompt to get a structured critique of a current design. Attach a screenshot before sending.

---

# Full Critique Prompt

```
I need a detailed design critique of the attached screenshot. Be specific and direct — name the exact problems, not vague suggestions.

Evaluate in this order:

1. VISUAL HIERARCHY
- Is there one dominant focal point per section, or do multiple elements compete equally?
- Can the eye travel from headline to subtext to CTA without confusion?
- Is there any element that has more visual weight than it deserves?

2. TYPOGRAPHY
- Is the headline-to-body size ratio at least 3x in the hero?
- Is there genuine weight contrast (not just size contrast)?
- Is the text color tiered (primary, secondary, tertiary levels)?
- Are there any flat typography areas where all text reads at the same visual volume?

3. SPACING
- Is section padding generous (80px+ vertical)?
- Does anything feel cramped or compressed?
- Is there breathing room around the primary focal element?

4. ANTI-SLOP PATTERNS PRESENT
- List any of these if present: purple/violet gradient background, glow/neon halos, excessive glassmorphism, identical three-column feature cards, over-centered layout, generic stock imagery, purposeless animations, scattered color palette, flat typography.

5. COLOR
- How many distinct colors are prominent? (Target: 3 maximum)
- Is the accent used sparingly or overused?
- Is text contrast sufficient?

6. EMOTIONAL TONE
- What emotion does this design communicate?
- Is that emotion consistent across every visible section?
- Does anything contradict the dominant tone?

7. PRIORITY PROBLEMS
List the top 3 problems in order of impact. For each:
- Problem: [name it specifically]
- Category: [structural / surface / detail]
- Fix: [one specific action to address it]

Do not suggest generic improvements. Name specific things that are wrong and exactly how to fix them.
```

---

# Quick Critique Prompt (Faster)

```
Critique this screenshot. I want:
1. The single biggest structural problem (hierarchy, layout)
2. The single biggest surface problem (color, type, spacing)
3. The single most important missing detail (hover states, transitions, polish)
4. Any anti-slop patterns present (name them specifically)

Be direct. No hedging. Tell me what is wrong and what to do.
```

---

# Section-Specific Critique Prompt

```
Critique only the [hero / features / testimonials / pricing / CTA] section in this screenshot.

For this section only:
- What is the focal point? Is it clear?
- Is the hierarchy correct?
- What is the worst problem?
- What would make this section feel premium?
- What does it have that good [hero / feature / etc] sections typically do?
- What is it missing?
```
