# Premium Landing Pages

Landing page case studies: what makes specific high-quality pages work.

---

# Linear — linear.app

Why It Works:
Linear's landing page is a masterclass in restraint. The design communicates "we made the decisions so you don't have to" — which is exactly the promise of their product.

Key techniques:
- Text opacity hierarchy: three levels of white at 92%, 55%, 35% — no additional colors
- Spacing so generous it feels architectural — section padding at 160px
- Product UI embedded directly in the hero — you see the product before you understand it
- Zero decorative elements — nothing on the page exists without justification
- Navigation is nearly invisible (low contrast) — content dominates
- Animations: scroll reveals at 450ms, hover states at 200ms — felt, not watched

What to extract:
The opacity-based text hierarchy. The willingness to use extreme whitespace. The principle that the product is the visual.

# Stripe — stripe.com

Why It Works:
Stripe manages to communicate a technically complex product clearly while maintaining premium visual quality. Their bento-style feature sections are some of the best examples of varied-weight feature layouts.

Key techniques:
- Gradient usage that is purposeful (directional, with clear intention) not random
- Code snippets treated as visual design elements, not just technical content
- Bento grid feature cards with genuine content diversity (not just different sizes)
- Social proof from recognizable enterprise logos, well integrated
- Alternating section backgrounds (white → light grey → white) creating rhythm without dividers
- Typography: DM Sans with strong weight hierarchy

What to extract:
How to present technical content (code) as a hero visual. How to use bento grids with genuine content variety. Background color variation as section rhythm.

# Vercel — vercel.com

Why It Works:
Near-zero color. Typography as the primary visual element. Bold claims stated plainly. Makes simplicity feel like a power move.

Key techniques:
- Black backgrounds with white text, nothing else — confidence through restraint
- Headlines that make bold claims without hedging: "Develop. Preview. Ship."
- No illustrative elements — the product screenshots are the visuals
- Navigation at absolute minimum visual weight — barely visible
- Grid of product cards using pure surface variation for depth (slightly lighter card on dark background)
- Motion: only entrance animations, very subtle

What to extract:
The confidence to have almost no design elements. Headlines that work without visual support. Navigation visual restraint.

# Raycast — raycast.com

Why It Works:
Raycast integrates product demonstration into the marketing page — users see the product working, not illustrated.

Key techniques:
- Custom gradient mesh backgrounds that feel material (purple-orange, unique to Raycast)
- Product UI shown in keyboard context — the hand/keyboard creates realistic usage context
- Scroll-linked product demonstrations that respond to scroll position
- Each section demonstrates a distinct capability through actual product behavior
- Custom cursor on desktop
- Motion: sophisticated, tied to product demonstration

What to extract:
Using actual product behavior as the marketing visual. How to create gradient mesh backgrounds. Scroll-linked feature demonstrations.

# Resend — resend.com

Why It Works:
Maximum restraint on a developer-focused product. Near-monochrome. Code as design. Makes technical content feel luxurious.

Key techniques:
- Dark background with almost no color — confidence in the absence of decoration
- Code syntax highlighting is the primary visual element in feature sections
- Simple, wide letter-spacing headlines communicate authority
- The simplicity itself communicates "we are secure enough to do nothing"
- API response objects shown as visual elements in the product breakdown

What to extract:
How a developer product can feel premium without visual decoration. Using code syntax highlighting as a visual. The restraint approach — removing everything unnecessary.

---

# Loom — loom.com

Why It Works:
Consumer-facing product with genuinely warm design. Breaks from the cold-tech default in a product category dominated by cold-tech defaults.

Key techniques:
- Warm neutral palette — not blue, not purple, not dark
- Video thumbnail as hero visual — immediately communicates the product
- Copy: conversational, slightly playful — matches the warm visual system
- Social proof: enterprise logos (trust) combined with usage stats (scale) — best of both
- Feature sections show real user faces in video thumbnails — human warmth

What to extract:
How to make a tech product feel warm and human. Aligning copy tone with visual tone. Using the product output (video thumbnails) as the visual system.

---

# Arc Browser — arc.net

Why It Works:
Arc intentionally breaks SaaS conventions. The design has personality and feels created by humans who care, not assembled from components.

Key techniques:
- Expressive, unconventional layouts that feel editorial rather than systematic
- Copy that is genuinely human and occasionally humorous
- Motion with real character — spring physics, expressive transitions
- Visual identity that feels like a world, not a product page
- Designed for the product's specific audience (creatives who value personality)

What to extract:
How to break SaaS conventions intentionally. Copy-visual alignment where both have the same personality. Motion that expresses brand character.
