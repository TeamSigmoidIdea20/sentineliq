# AI-Native Development

---

# Core Principle

AI does not replace skilled builders.

AI amplifies:
- execution speed
- iteration velocity
- implementation capacity
- debugging efficiency
- experimentation

The strongest AI-native developers combine:
- engineering fundamentals
- product intuition
- rapid iteration
- agent orchestration
- workflow automation

AI is a force multiplier, not a substitute for thinking.

---

# AI-Native Engineering

Modern development is shifting from:
manual implementation

toward:
high-level orchestration and supervision.

The developer increasingly becomes:
- architect
- product strategist
- reviewer
- systems thinker
- workflow orchestrator

# Claude Code Philosophy

Claude Code is most valuable when used to:
- accelerate implementation
- reduce repetitive work
- scaffold systems quickly
- iterate rapidly
- debug efficiently
- refactor safely
- maintain momentum

Weak usage:
blindly generating massive systems without understanding them.

Strong usage:
directed iterative collaboration.

# Prompting Principles

Strong prompting:
- defines constraints clearly
- scopes tasks narrowly
- explains intent
- provides references
- iterates incrementally

Weak prompting:
- vague objectives
- giant open-ended requests
- no architecture guidance

---

# Debugging Philosophy

AI speeds debugging but does not eliminate it.

Strong debugging workflow:
1. isolate issue
2. understand root cause
3. inspect assumptions
4. apply focused fixes
5. verify behavior

Avoid:
blind patch stacking.

# AI Development Anti-Patterns

---

# Blind Trust

Problem:
accepting generated systems without review.

Effects:
- fragile architecture
- hidden bugs
- technical debt

---

# Massive One-Shot Generation

Problem:
asking AI to build entire systems at once.

Effects:
- inconsistency
- hallucination
- maintenance problems

---

# Tool Obsession

Problem:
constantly switching tools instead of shipping.

Effects:
- workflow instability
- distraction

---

# AI Dependency Without Fundamentals

Problem:
builder cannot reason independently.

Effects:
- inability to debug
- poor architecture decisions
- scaling problems

---

# Overengineering With AI

Problem:
AI accelerates unnecessary complexity.

Effects:
- bloated systems
- slower iteration
- maintenance overhead
