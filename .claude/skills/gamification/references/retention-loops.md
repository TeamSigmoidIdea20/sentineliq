- visibility
- recognition
- audience growth

- mastery
- completion
- skill growth

# Productivity Loop

Complete Task → Satisfaction → Momentum → More Tasks

Key Drivers:
- completion drive

# Social Community Loop

Participate → Recognition → Belonging → Participate Again

Key Drivers:
- relatedness
- identity
- social proof

# Collection Loop

Key Drivers:
- relevance
- curiosity

# Competition Loop

Key Drivers:
- competence
- status
- achievement
